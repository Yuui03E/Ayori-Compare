# Ayori logo concepts

Original SVG studies prepared for the user's selection. These are proposals, not the installed app identity.

- **A — Facet:** asymmetric A monogram; pale mint, warm white and a darker green facet. Recommended for its recognizable initial and compact silhouette.
- **B — Twinlight:** opposing lens halves around a shared diamond; soft violet, mint and white.
- **C — Parallax:** two offset frame corners enclosing one pixel; mint, champagne and white.

`index.html` presents all three with wordmarks, a 32px title-bar mockup, 16/24/32px marks, a 48px icon treatment and one-color samples. `ayori-logo-directions.png` is the combined preview; individual `*-preview.png` files are larger card previews. The SVG files are editable source artwork with transparent backgrounds.

Recreate the HTML and PNG previews with `node design/logo-concepts/preview.mjs` (uses the project's Playwright dependency and installed Edge). No image-generation API or external images were used.

After selection, refine the chosen mark if needed, integrate it into Ayori's title bar and Home, regenerate native app icons from the approved artwork, then build and verify the packaged Windows app. Keep the compact bar dimensions and original fonts.
